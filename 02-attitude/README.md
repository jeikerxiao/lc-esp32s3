# 实验 02：QMI8658 姿态传感器（倾角测量）

## 简介

本实验通过 I2C 总线驱动板载的 QMI8658 六轴惯性传感器（3 轴加速度计 + 3 轴陀螺仪），读取加速度数据并计算出开发板在 X、Y、Z 三个方向上的倾斜角度，每秒在串口打印一次。这是学习 I2C 通信和传感器数据解算的入门实验。

## 原理

### QMI8658 简介

QMI8658 是一款六轴运动传感器，内部集成了：
- **加速度计**：测量三个轴向的加速度（含重力加速度）
- **陀螺仪**：测量三个轴向的角速度

它通过 I2C 接口与主控通信，I2C 器件地址为 `0x6A`。

### 倾角解算原理

当开发板静止时，加速度计测量的主要是重力加速度 g（约 9.8 m/s²）。重力方向始终竖直向下，当板子倾斜时，重力在三个轴上的分量会发生变化。通过反三角函数即可求出倾角：

```
AngleX = atan( acc_x / sqrt(acc_y² + acc_z²) ) × (180/π)
AngleY = atan( acc_y / sqrt(acc_x² + acc_z²) ) × (180/π)
AngleZ = atan( sqrt(acc_x² + acc_y²) / acc_z ) × (180/π)
```

其中 `57.29578` 就是 `180/π`，用于把弧度转换为角度。

> 注意：这种解算方式只适合静态或缓慢变化的场景。在剧烈运动或振动时，加速度计会叠加运动加速度，结果会抖动。要获得平滑的姿态需要融合陀螺仪数据（互补滤波或卡尔曼滤波），本实验未涉及。

### I2C 通信

I2C（Inter-Integrated Circuit）是一种两根线（SDA 数据线 + SCL 时钟线）的同步串行总线，支持挂载多个器件。本实验使用 ESP32-S3 的 I2C0 外设，工作频率 100kHz（标准模式）。

## 硬件接线

QMI8658 焊接在开发板上，通过板载 I2C 总线连接，无需额外接线。

| 信号 | GPIO | 说明 |
|------|------|------|
| I2C SDA | GPIO1 | 数据线，内部上拉 |
| I2C SCL | GPIO2 | 时钟线，内部上拉 |

I2C 外设编号：`I2C_NUM_0`，时钟频率：100kHz，QMI8658 器件地址：`0x6A`。

## 代码讲解

工程目录结构：

```
02-attitude/
├── CMakeLists.txt
├── sdkconfig.defaults
└── main/
    ├── CMakeLists.txt
    ├── esp32_s3_szp.c      # 板级支持：I2C 初始化 + QMI8658 驱动
    ├── esp32_s3_szp.h      # 引脚宏定义 + 寄存器枚举 + 数据结构
    └── main.c              # 主程序
```

### 关键流程

`main.c` 中 `app_main()` 执行以下步骤：

1. `bsp_i2c_init()`：初始化 I2C0 总线（Master 模式，GPIO1/GPIO2，内部上拉，100kHz）。
2. `qmi8658_init()`：初始化 QMI8658 传感器。
3. 主循环：每隔 1 秒调用 `qmi8658_fetch_angleFromAcc()` 读取倾角并打印。

### QMI8658 初始化

`qmi8658_init()`（在 `esp32_s3_szp.c`）依次完成：

1. **读取 WHO_AM_I 寄存器**（地址 0x00），确认返回值为 `0x05`，证明芯片在位。若读不到会每秒重试（死循环等待）。
2. **软复位**：向 RESET 寄存器（0x60）写 `0xb0`，延时 10ms。
3. **配置寄存器**：
   - CTRL1 = `0x40`：使能地址自动递增（便于连续读取）
   - CTRL7 = `0x03`：同时使能加速度计和陀螺仪
   - CTRL2 = `0x95`：加速度计量程 ±4g，输出速率 250Hz
   - CTRL3 = `0xd5`：陀螺仪量程 ±512dps，输出速率 250Hz

### 读取原始数据

`qmi8658_Read_AccAndGry()` 先查询 STATUS0 寄存器确认数据就绪，然后从 AX_L 寄存器开始一次性连续读取 12 字节（依赖地址自增），按小端序解析为 6 个 int16 原始值：`acc_x/y/z`、`gyr_x/y/z`。

### 倾角解算

`qmi8658_fetch_angleFromAcc()` 调用上面的读取函数，再用 `atan` + `sqrt` 计算三个轴的倾角，存入结构体 `t_sQMI8658` 的 `AngleX/AngleY/AngleZ` 字段。

## 实验效果

编译烧录后打开串口监视器，会看到：

```
I (xxx) main: I2C initialized successfully
I (xxx) esp32_s3_szp: QMI8658 OK!
I (xxx) main: angle_x = 0.5   angle_y = -1.2   angle_z = 0.0
```

之后每秒刷新一行角度值。将开发板倾斜或翻转，对应轴的角度会实时变化：
- 水平放置时，AngleX、AngleY 接近 0°，AngleZ 接近 0°
- 倾斜板子，相应轴的角度在约 ±90° 范围内变化

## 注意事项

1. **使用的是旧版 I2C 驱动**：代码使用 `driver/i2c.h`（legacy API）。在较新的 ESP-IDF（v5.2+）中会有 deprecated 警告，但仍可正常编译运行。
2. **初始化失败会死循环**：如果 WHO_AM_I 读不到 `0x05`（例如传感器虚焊、I2C 接线错误），程序会卡在 `qmi8658_init()` 里每秒重试，串口看不到 "QMI8658 OK!"。此时应检查硬件。
3. **倾角仅由加速度计解算**：运动或振动状态下结果会抖动，这不是真正的姿态融合。陀螺仪数据虽然读了，但未参与角度计算。
4. **量程与速率固定**：加速度 ±4g、陀螺仪 ±512dps、250Hz 均写死在初始化中，如需修改可调整 CTRL2/CTRL3 寄存器值。

## 总结

本实验以 QMI8658 为载体，完整演示了 I2C 传感器的使用套路：初始化总线 → 校验芯片 ID → 配置工作寄存器 → 读取原始数据 → 算法解算。理解了这套流程，后续驱动其他 I2C 器件（如 ES8311、PCA9557、触摸屏等）都会非常顺畅。同时，本实验也揭示了加速度计测倾角的局限性，为后续学习姿态融合算法埋下伏笔。
